# Code of Conduct

## Our standards

SotyRoute is a professional tool for authorized security work.  
We expect contributors to interact professionally and constructively.

Acceptable behaviour:

- Technical critique of ideas, not personal attacks.
- Respectful disagreement with clear reasoning.
- Assuming good faith until demonstrated otherwise.
- Staying on-topic: security engineering, authorized lab workflows, Windows networking.

Unacceptable behaviour:

- Harassment, intimidation, or personal attacks.
- Requests to add features enabling unauthorized access or illegal activity.
- Promoting SotyRoute or any routing tool as an anonymity guarantee.
- Sharing or encouraging the sharing of private information without consent.

## Enforcement

Violations may result in comment removal, temporary ban, or permanent ban from the project, at the maintainer's discretion.

Report concerns privately to the maintainer: open a GitHub Security Advisory or contact [@descambiado](https://github.com/descambiado) directly.

## Scope

This Code of Conduct applies within all project spaces (GitHub issues, PRs, discussions, releases) and in public spaces when an individual is representing the project.
