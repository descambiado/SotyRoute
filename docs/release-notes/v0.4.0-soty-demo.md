# v0.4.0 — SOTY Real Signals (Draft)

**Status:** draft milestone note — not a tagged release yet.
**Date:** 2026-08-04

## Summary

The SOTY Score's headline sub-scores now read real signals instead of only precomputed demo
numbers. Four of the five sub-scores — **Route (30%)**, **Host (20%)**, **Intel (10%)** and
**Evidence (15%)**, together three-quarters of the overall weight — reflect the actual machine
and the operator's own choices. **Scope (25%)** remains demo-only, intentionally.

## What's new

- **Route** — real via Route Guard: DNS servers, public IP (opt-in), tunnel installation/process
  state, proxy configuration, route table readability.
- **Host** — real via Host Guard: firewall state, Defender state, proxy configuration, known
  tunnel processes, elevation. (Collected since an earlier PR; this milestone is also where it
  first started actually feeding the displayed Score.)
- **Intel** — real via Route Pack selection and Ethical OSINT Navigator category/risk filters —
  no new system signal needed, this state already existed in the UI and simply wasn't read by
  the score before.
- **Evidence** — real via Evidence Guard: evidence directory readiness, recorded session count,
  and the operator's actual BOFA/SotyHUB export settings.

## What's intentionally unchanged

- **Scope remains demo.** Wiring it for real needs a shared "active profile" concept across
  pages (today each page — Profiles, SotyDashboard — keeps its own local state, with nothing
  connecting them) plus a new UX for the operator to declare an investigation target and have it
  checked against the loaded profile's allow/block lists. That's a design task in its own right,
  not a mechanical wiring job like the other four — tracked as follow-up work, not started here.

## Safety & scope boundaries (unchanged)

- Evidence files are local-only, written to `~/.sotyroute/runs/<timestamp>_soty/`.
- BOFA/SotyHUB exports are local-only.
- No BOFA launch.
- No SotyHUB upload.
- No external APIs.
- No scraping.
- No anonymity guarantee.
- No offensive execution.

## Deferred / not part of this milestone

- **Scope real-signal architecture** — requires shared active-profile state across pages plus a
  target-declaration UX. See above.
- **react-router-dom 7.18.2** (Dependabot #52) — deferred. The high-severity advisory it once
  traded against (GHSA-qwww-vcr4-c8h2) turned out to be scoped to the unstable RSC APIs, which
  this app doesn't use anywhere — but `npm audit --audit-level=high`, a required CI gate, can't
  express that nuance and still fails on 7.18.2. No published `react-router-dom` release yet
  satisfies both the old moderate-CVE fix and this advisory at once.
- **TypeScript 7.0** (Dependabot #44) — deferred; the native Go rewrite is still very new and the
  surrounding tooling ecosystem hasn't caught up yet.
- **Tauri 2.x migration** (Dependabot #15 / #5) — deferred; a large enough change to warrant its
  own dedicated session rather than riding along with this milestone.
